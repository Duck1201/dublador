# ADR-0010 — CLI Typer com seletor fzf opcional

- **Status:** Aceito
- **Data:** 2026-10-09

## Contexto
O plano diz que o usuário "escolhe um vídeo" pela CLI. Um seletor interativo é conveniente; argumentos diretos são scriptáveis e testáveis.

## Decisão
CLI construída com **Typer**, comando `dublador`. `dublador run VIDEO` é a interface principal; sem argumento, abre um seletor com `fzf` (ou um prompt de caminho se `fzf` não existir). O seletor só preenche argumentos — o núcleo é 100% não interativo. Subcomandos: `run`, `resume`, `status`, `clean`, `setup`, `doctor`.

## Consequências
- Lote, fila e pasta observada ficam fora do escopo inicial, mas um `for f in *.mp4; do dublador run "$f"; done` já funciona.
