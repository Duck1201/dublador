# stagekit

Contrato de arquivos compartilhado entre o orquestrador `dublador` e os estágios: parsing da interface de estágio, leitura da config snapshot, escrita atômica, JSON Schemas versionados e emissor de progresso. Não contém modelos nem código de nenhum estágio ([ADR-0007](../../docs/adr/0007-venv-por-estagio-e-contrato-de-arquivos.md)).
